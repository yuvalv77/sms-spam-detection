# SMS Spam Detection

Machine Learning project for classifying SMS messages as **Spam** or **Ham**.

## Project overview

The project uses a Kaggle SMS spam dataset and follows five main stages:

1. Introduction, dataset inspection, cleaning, train/test split, and evaluation metric selection.
2. Feature Engineering using Bag of Words with `CountVectorizer`.
3. Multinomial Naive Bayes implemented from scratch.
4. Hyperparameter selection using 5-fold stratified cross-validation.
5. Final evaluation on a held-out test set using Precision, Recall, and F1-score for the Spam class.
